# 奶蛙学 · 翻阅

《奶蛙学》基础教程 · 必修 · 第一册的网页阅读版，完整保留 141 页原版排版。

**在线阅读：https://zmmm-h.github.io/naiwa-book/**

支持桌面双页翻阅、手机单页、连续阅读、目录跳转、全文搜索、书签、页面放大和本地进度保存。

## 部署

纯静态站点，无依赖、无服务端。GitHub Pages 从 `main` 分支根目录发布，提交更新后自动重新部署。

- `index.html`：界面与目录、搜索文字、书内链接数据
- `assets/reader.*.css`、`assets/reader.*.js`：样式与交互
- `assets/page-*.webp`：141 张原版书页，按需加载

资源名包含内容摘要，方便浏览器缓存与后续更新。所有内容均由本站提供，不使用第三方字体、脚本或统计服务。阅读进度与书签仅保存在访问者自己的浏览器。

## 内容与设计

原书内容、插图及原有署名保留。页面阅读器的发布不改变原书内容的权利归属。
